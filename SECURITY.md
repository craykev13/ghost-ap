Security Policy

Reporting a Vulnerability

If you discover a security vulnerability in GhostAP, please report it privately through GitHub’s private vulnerability reporting.

Please do not disclose security vulnerabilities through public issues or pull requests before they have been addressed.

When reporting a vulnerability, please include:

* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue.
* The affected GhostAP version or commit.
* Hardware model and operating system, where relevant.
* Any relevant logs or proof of concept, with sensitive information removed.

Supported Versions

Security fixes are provided for the latest version of GhostAP on the main branch.

Responsible Disclosure

Please allow a reasonable amount of time to investigate and address reported vulnerabilities before publicly disclosing them.

Good-faith security research and responsible disclosure are appreciated.
